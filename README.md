# Annhylde
渗透测试 + 代码审计 + 开发 Agent

【工具介绍】

Annhylde 是一款自研开发的 AI Agent 工具，采用全新语言和架构，并且在此基础上，增加了团队模式、plan模式等，

该工具吸取了AIZoo工具的经验，在代码开发、代码审计、渗透测试等场景上的整体效果强于AIZoo

桌面版本不依赖Annhylde，直接运行即可，图形的，点点就会了，我觉得不需要额外介绍，agent树就是团队模式下其他agent的状态

建议使用cmd运行，运行后根据提示在指定配置文件处添加密钥即可，建议使用deepseek-v4-flash
